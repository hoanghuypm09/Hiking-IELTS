# Sổ Học IELTS (Hiking IELTS)

Website tự học IELTS band 4.0–5.0, đi theo lộ trình 10 unit của sách *Complete IELTS Bands 4–5*.

Mỗi unit gồm: từ vựng (flashcard, phát âm, quiz), ngữ pháp, Reading, Listening, Writing (có biểu đồ Task 1 và bài mẫu) và Speaking (Part 1–3, đồng hồ Part 2). Sau mỗi 2 unit có bài ôn tập. Tiến độ được lưu trên trình duyệt (localStorage).

Bài đọc, bài nghe, câu hỏi và bài mẫu là nội dung tự soạn, không sao chép từ sách.

## Cấu trúc

- `index.html`: giao diện và logic
- `units-1-5.js`, `units-6-10.js`: nội dung từng unit (sửa hoặc thêm unit ở đây)

## Chạy

Mở `index.html` trong trình duyệt, hoặc bật GitHub Pages (Settings → Pages → Deploy from branch `main`, thư mục `/`).
